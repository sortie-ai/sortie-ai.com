04Unattended

What it handles
while you are not watching.

  • CI turns red → the failure goes back to the agent

    CI failedAgent

  • A reviewer comments → routed into the same session

  • Tokens add up → capped per issue, before it overspends

  • The process dies → picks up where it stopped
