# Sortie

> {{ site.Params.description }}

Sortie is an autonomous coding agent orchestrator. Engineers manage work at the ticket level — Sortie handles the rest: isolated workspaces, retry logic, state reconciliation, tracker integration, and cost tracking. Single binary, zero dependencies, SQLite persistence. Apache-2.0. The binary sends no telemetry.

This is the project's landing page. The documentation site carries the full content index, and every page there is also available as clean Markdown via the `Accept: text/markdown` request header.
